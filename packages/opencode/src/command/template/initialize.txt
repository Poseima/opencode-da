### Section 3: Build/Lint/Test Commands

### Section 4: Code Conventions for Data Engineering
Include these data engineering best practices:
- **Metadata**: Always create metadata files (`{filename}_metadata.py`) for data files
- **File naming**: Use Chinese file names for data files and analysis outputs
- **Stats tables**: Include frequency (频率), penetration (渗透率), and proportion (占比) columns
- **Folder structure**: Create new directories for new analytics tasks with clear business meaning
- **Crosstab format**: Horizontally merge frequency and penetration matrices, add column suffixes (_频次, _渗透率)

### Section 5: Available Data Engineering Tools
List these tools:
- **init_data_metadata**: Generate comprehensive metadata for CSV/Excel files
- **keyword_clustering**: Cluster text data by keyword matching
- **semantic_clustering**: Cluster text data by semantic similarity
