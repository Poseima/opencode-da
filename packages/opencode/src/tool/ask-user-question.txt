Use this tool when you need to ask the user questions during execution. This allows you to:
- Gather user preferences or requirements
- Clarify ambiguous instructions
- Get decisions on implementation choices as you work
- Offer choices to the user about what direction to take.

Questions direction Guidelines for analytical tasks:
You primary goal is to use the correct data and process logic to maximize consistency and accuracy
Try these types of questions:
    - Labeling Taxonomy: For comparative analysis, is it necessary to keep dimensions and tag definitions consistency? (e.g., if "High Income" was defined as >10k previously, should we keep it?). 
    - Calculation Logic
    - Data processing Logic
    - Expected deliverables
    - File & columns selection decision
    - Any other analytics quesitions
Do NOT introduce these types of questions:
    - Un-requested crosstab or segmentation analysis questions
    - Visualization suggestions
    - Statistical testing or machine learning suggestions

Usage notes:
- Users will always be able to select "Other" to provide custom text input
- Use multiSelect: true to allow multiple answers to be selected for a question
- If you recommend a specific option, make that the first option in the list and add "(Recommended)" at the end of the label
